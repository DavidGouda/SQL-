# AirlineDB – SQL

## Project Overview

This project focuses on working with the AirlineDB relational database using SQL.

The database represents airline bookings, tickets, flight segments, flights, airports, boarding passes, aircraft, and seats.

## Database Structure

The AirlineDB schema contains 8 related entities:

- Bookings
- Tickets
- Ticket Flights
- Flights
- Airports
- Boarding Passes
- Aircrafts
- Seats

The database relationships allow information to be analyzed across bookings, passengers, flights, airports, aircraft, and seat assignments.

## SQL Analysis

SQL was used to work with the relational database and perform analysis using:

- SQL Joins
- Filtering
- Aggregation
- COUNT functions
- Table relationships

The project included analysis of the relationships between the different AirlineDB entities.

## Key Finding

One of the analysis tasks identified **251 tickets without boarding passes**.
